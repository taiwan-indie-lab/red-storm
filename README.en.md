# Red Storm 紅色風暴

**English** | [中文](README.md)

An isometric real-time strategy game (RTS) made with Godot 4. Two factions, 12 countries, and a modern setting of drones, electronic warfare, financial sanctions and hybrid war.

**▶ Play in your browser: https://taiwan-indie-lab.github.io/red-storm/**

> A desktop Chrome / Edge / Firefox is recommended. The first load is about 90 MB, so please be patient; click the screen once to enable sound, and press Esc to skip the intro.
> The web version keeps its saves in your browser.
> The game has Chinese and English text and voices. It picks a language from your system on first launch; use the `English` / `中文` button on the main menu to switch.

## Features

- **Two factions, 12 countries**: each country has its own units and special ability (Paratroopers, Hsiung Feng Missile, Dongfeng Express, Strait Blockade...)
- **Modern warfare**: FPV and loitering-munition drones, electronic jamming, HIMARS, Javelin missiles, aircraft carriers
- **Hybrid warfare**: financial sanctions, energy cutoffs, GPS jamming, spy infiltration, diplomatic alliances and ceasefires
- **Game modes**: Annihilation, Survival (25 waves), Control Point, plus story campaigns
- **Daily Challenge**: a fixed battlefield and set of rule mutators each day - go for the fastest win
- **Rule mutators**: Fast Build, Rich Ore, Nuclear Age, Glass Cannon, Infantry War...
- **Dynamic weather, tech buildings, battlefield contracts, tech upgrades, unit abilities, AI commander personalities**
- Random start positions, procedurally generated maps, records and achievements

## Basic Controls

| Input | Action |
|---|---|
| Hold right mouse button and drag | Pan the view (arrow keys and two-finger trackpad swipe also work) |
| Left click / drag | Select units, box-select |
| Right click | Move, attack, harvest, capture |
| A | Attack-move |
| F | Unit ability (infantry dig in, vehicle smoke) |
| D | Deploy the MCV |
| Ctrl + number | Control groups |
| Space | Jump to the latest alert |
| M | Music on / off |
| F1 | Full in-game help |
